# tutorial-knowledge-graph

## 参考書

- [Aidan Hogan et al., Knowledge Graphs](https://kgbook.org/)

## 使用ライブラリ

- [RDFLib](https://rdflib.readthedocs.io/) — RDFグラフの作成・読み込み・検索
- [pyoxigraph](https://pyoxigraph.readthedocs.io/) — OxigraphのRDFストアとSPARQLクエリ
  - [oxrdflib](https://github.com/oxigraph/oxrdflib) — RDFLibとOxigraphの連携
- [pySHACL](https://github.com/RDFLib/pySHACL) — SHACLによるRDFデータの検証
- [OWL-RL](https://owl-rl.readthedocs.io/) — RDFS / OWL 2 RLの推論
- [NetworkX](https://networkx.org/) — グラフ構造の作成・探索
- [yFiles Jupyter Graphs](https://github.com/yWorks/yfiles-jupyter-graphs) — Jupyter Notebook上でのグラフ可視化
